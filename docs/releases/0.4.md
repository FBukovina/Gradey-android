# Gradey Android 0.4 — refreshed app icons

Version 0.4 updates the phone app's launcher and notification icons.

- New launcher artwork with adaptive, round and monochrome themed icon variants.
- Dedicated notification icons for planner reminders, grade notifications and downloaded updates.
- The interface and features introduced in 0.3 remain available.

## Availability and compatibility

[Download the phone APK](https://github.com/FBukovina/Gradey-android/releases/download/v0.4/gradey-0.4-debug.apk) from the [0.4 release](https://github.com/FBukovina/Gradey-android/releases/tag/v0.4).

This is a direct-download debug preview. Version 0.4 uses internal code 7 and the existing direct-download signing key, allowing compatible installations of 0.3 (code 6), 0.2.2 (code 5), 0.2.1 (code 3) and local previews (code 4) to update while retaining app data.

Open **Settings → Support & About → App updates → Check for updates**, download the update, and confirm installation in Android. App updates is also available from Gradey tools and the sign-in screen. The release is published as the latest non-prerelease so the direct updater can discover it.

Demo installations stay in demo mode after updating. Choose **Connect my school** under **Settings → Account** to connect a real Gradey ID or school account.

This release publishes the phone APK only. The Wear OS source includes the matching launcher artwork, but the companion remains independently versioned at 0.2.0 and is not installed by the phone updater.

## Known limitations

The preview retains the public Google/Supabase account configuration from 0.3. Live Gradey AI, Apple browser sign-in, Android mark-push delivery and Play/RevenueCat purchases still require service configuration and acceptance. Native support uses browser Help until configured. Real Google/school account, physical-device and paired-Wear acceptance remain pending. **Use demo data** uses sample repositories; **Continue without Gradey ID** uses real school providers stored locally on the device.

This release does not deploy backend changes or submit the app to Google Play. See [the parity audit](../ios-parity.md) and [configuration requirements](../android-configuration.md) for remaining setup and validation.
