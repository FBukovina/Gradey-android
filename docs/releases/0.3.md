# Gradey Android 0.3 — phone interface refresh

This update gives the phone app a consistent Gradey look and reorganizes the daily overview and settings.

- Shared teal and emerald colours, soft background accents, Space Grotesk headings, rounded cards and Hugeicons across the phone interface.
- Redesigned Today screen with a time-aware greeting, school-account switcher, current and next lesson details, and a compact lesson timeline.
- Refreshed recent-grade, planner, attention, absence-risk and lunch cards. Recent grades can open their subject directly, and the lunch card follows the Meals tab preference.
- A grouped Settings hub for Account, Connected services, Notifications, Privacy & Data, Language and preferences, and Support & About.
- Updated floating navigation, page headers, grade badges and controls across marks, absence, timetable, meals, sign-in, Gradey AI and app updates.

## Availability and compatibility

[Download the phone APK](https://github.com/FBukovina/Gradey-android/releases/download/v0.3/gradey-0.3-debug.apk) from the [0.3 release](https://github.com/FBukovina/Gradey-android/releases/tag/v0.3).

This is a direct-download debug preview, not a completed production release or a Play Store submission. Version 0.3 uses internal code 6 and the same signing identity as public 0.2.2 (code 5), public 0.2.1 (code 3), and local parity previews (code 4). Android retains existing app data during a compatible update.

Existing compatible installations can open **App updates → Check for updates**, download the update, and confirm installation in Android. In 0.3, App updates is available from **Settings → Support & About**, Gradey tools, or the sign-in screen. The updater reads GitHub's latest non-prerelease release and its `gradey-update.json`; that distribution label does not establish production readiness.

If the old installation was using demo data, it stays in demo mode after updating. Choose **Leave demo** under **Settings → Account** before connecting a real Gradey ID or school account.

This release publishes the phone APK only. The Wear OS companion remains independently versioned at 0.2.0 and is not installed by the phone updater.

## Known limitations

The preview retains the public Google/Supabase account configuration from 0.2.2. Live Gradey AI, Apple browser sign-in, Android mark-push delivery and Play/RevenueCat purchases still require service configuration and acceptance. Native support uses browser Help until configured. Real Google/school account, physical-device and paired-Wear acceptance remain pending. **Use demo data** uses sample repositories; **Continue without Gradey ID** uses real school providers stored locally on the device.

No production backend is deployed by this APK release. See [the parity audit](../ios-parity.md) and [configuration requirements](../android-configuration.md) for the remaining gates.
